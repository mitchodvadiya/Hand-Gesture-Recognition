# Experimental Pipeline & CNN Baseline Validation Report

**Date & Time:** October 30, 2026  
**Evaluated Model:** `BaseInceptionCNN` (Base Paper 6-Module Inception Architecture)  
**Dataset:** EMG-EPN-612 (8-channel Myo Armband)  
**Hardware Device:** CPU  
**Smoke-Test Metrics:** Accuracy: **73.87%**, Macro F1-score: **72.59%**  

---

## 1. Participant IDs in Each Split
The EMG-EPN-612 training dataset contains **306 participant directories** (`user1` through `user306`).

- **Total Users:** 306
- **Training Set (80%):** 244 participants (`shuffled_indices[:244]`)
- **Validation Set (20%):** 62 participants (`shuffled_indices[244:]`)

In the cached subset (`train_seq_cache.pt` and `val_seq_cache.pt`):
- **Train Participants:** 10 participants (`user143`, `user255`, `user293`, `user103`, `user219`, `user131`, `user132`, `user237`, `user126`, `user125`)
- **Validation Participants:** 10 participants (`user23`, `user290`, `user14`, `user305`, `user117`, `user181`, `user198`, `user274`, `user192`, `user213`)

## 2. Participant Disjointness Verification
- **Intersection:** $\text{TrainParticipants} \cap \text{ValidationParticipants} = \emptyset$ (0 participants overlap).
- **Verification:** The split index divides the permuted list into two strictly non-overlapping slices (`[:split_idx]` and `[split_idx:]`). No participant ID appears in both splits.
- **Verdict:** **PASS (Strict Participant Independence Confirmed)**.

---

## 3. Recording Window Isolation
- **Windowing level:** Sliding window segmentation is performed **within** each 5-second continuous trial recording.
- **Partitioning level:** The train/val split is performed at the **participant directory level** *before* reading any files or windowing signals.
- **Integrity:** Every recording trial and all sliding frames derived from it belong exclusively to the participant who performed it, and that participant resides in only one split.
- **Verdict:** **PASS (Zero window or trial leakage across splits)**.

## 5. Ground-Truth Label Provenance
- **Sequence Labels:** Taken directly from the acquisition visual stimulus metadata key `"gestureName"`.
- **Frame Labels:** Generated by comparing sliding windows against the binary `"groundTruth"` contraction vector:
  - If a window contains $\ge 75\%$ active contraction samples (`TOLERANCE_WINDOW = 0.75`), or $\ge 50\%$ of the total contraction duration, it is labeled with the prompt gesture.
  - Otherwise, it is labeled `"noGesture"`.
- **Verdict:** **PASS (Genuine ground-truth annotations from experimental protocol)**.

---

## 6. Preprocessing & Normalization Independence
- **Normalization:** Raw 8-bit integer EMG values are divided by the fixed hardware constant $128.0$.
- **Filtering:** 5th-order Butterworth low-pass filter with fixed coefficients derived from sampling frequency ($200\text{ Hz}$) and cutoff ($10\text{ Hz}$).
- **Spectrogram:** Fixed 24-sample Hanning window and fixed 0–12 Hz discrete Fourier basis matrix.
- **Information Leakage:** No sample mean, dataset standard deviation, or population statistics are computed across the dataset. Every recording is transformed independently.
- **Verdict:** **PASS (Zero data leakage between validation and training data)**.

## 7. Explanation of 1500 Sequences in Both Caches
- **Why both caches contained 1500 sequences:**
  In EMG-EPN-612, each participant produces exactly 150 trials ($25 \text{ reps} \times 6 \text{ classes} = 150$).
  During an earlier debugging execution where `max_users = 10` was used:
  - Train: $10 \times 150 = 1,500$ sequences, saved to `train_seq_cache.pt`.
  - Val: $10 \times 150 = 1,500$ sequences, saved to `val_seq_cache.pt`.
- **The Issue:**
  The cache filename was static: `self.cache_file = os.path.join(Config.CACHE_DIR, f"{data_split}_seq_cache.pt")`.
  When a subsequent smoke test requested `max_users = 5`, the loader found the existing file and loaded the cached 1,500 sequences (10 users) without re-slicing.
- **Correction Applied in `dataset.py`:**
  Cache filenames now encode the user count tag:
  `cache_tag = f"_u{max_users}" if (max_users is not None and max_users > 0) else "_all"`
  `self.cache_file = os.path.join(Config.CACHE_DIR, f"{data_split}_seq_cache{cache_tag}.pt")`

## 8. BaseInceptionCNN Architecture Verification
Comparing `models.py:BaseInceptionCNN` against MATLAB `CNN/modelCreation.m`:
- **Model Type:** Deep Convolutional Neural Network (CNN).
- **Backbone Structure:** 6 multi-scale Inception modules (`1a`, `1b`, `1c`, `1d`, `1e`, `1f`).
  - Branch 1: $1\times 1$ conv (18 filters).
  - Branch 2: $1\times 1$ reduce (16 filters) $\to$ $3\times 3$ conv (18 filters, pad 1).
  - Branch 3: $1\times 1$ reduce (16 filters) $\to$ $5\times 5$ conv (18 filters, pad 2).
  - Branch 4: $3\times 3$ maxpool (pad 1) $\to$ $1\times 1$ conv (18 filters).
  - Concat depth = $18 \times 4 = 72$ channels.
  - Residual Skips: Output of `1a` added into `1c`; output of `1c` added into `1e`.
  - Normalization: Batch normalization on the final module `1f`.
- **Classification Head:** Linear layer ($72 \times 13 \times 24 \to 6$ classes).
- **Verdict:** **PASS (Exact 1-to-1 reproduction of the reference paper's CNN architecture)**.

## 9. Validation Accuracy and Macro F1-Score Formulation
- Sequence predictions are filtered using the base paper's temporal label filter (`mode='1-1'`), followed by threshold majority voting ($\ge 4$ active labels).
- Overall Accuracy: $\frac{\text{Total Correct Sequences}}{\text{Total Evaluated Sequences}} = 73.87\%$.
- Macro F1-score: Unweighted arithmetic average of per-class F1-scores:
  $$\text{Macro } F1 = \frac{1}{6} \sum_{c=1}^6 F1_c = 72.59\%$$
- **Verdict:** **PASS (Matches standard evaluation metrics formulation)**.

The experimental pipeline is strictly participant-independent, free of cross-split data leakage, mathematically sound, and faithful to the reference paper.
